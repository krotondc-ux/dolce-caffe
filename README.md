# Dolce Caffè

Gestionale (cassa, magazzino, crediti, offerte, ordini rappresentanti) per lo spaccio Dolce Caffè.

- `index.html` app, `catalogo.json` listino GM 2000, `img/` foto prodotti (600x600, sfondo bianco).
- Foto: workflow **Foto prodotti** (Actions → Run workflow) cerca, scontorna e impagina le foto dal codice a barre. `tools/mancanti.json` elenca gli articoli ancora senza foto.
